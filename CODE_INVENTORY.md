## Current Main Story

### Current Experiment Question

The current experiment asks whether a BGAM can recover a known
spatial-temporal EEG effect from simulated multi-electrode data.

### Spatial Weight

The simulated signal is centred at electrode `CZ`. For each electrode, compute
its distance from `CZ`:

$$
d_i = \left\|p_i - p_{\mathrm{CZ}}\right\|_2
$$

The spatial weight is a hard-thresholded Gaussian:

$$
w_i =
\begin{cases}
\exp\left(-\dfrac{d_i^2}{2\sigma_{\mathrm{space}}^2}\right),
& d_i \le \sigma_{\mathrm{space}},\\
0,
& d_i > \sigma_{\mathrm{space}}.
\end{cases}
$$

This is implemented in `code/00_generate_data.R`.

### Active Electrodes

The Gaussian spatial function first gives each electrode a continuous weight
`w_i`. To define the discrete ground-truth active electrodes, this continuous
field is converted into an active/inactive label by a hard distance threshold.

The threshold is the one-SD spatial radius around `CZ`:

$$
d_i \le \sigma_{\mathrm{space}}.
$$

This is the distance-based version of the "mean ± 1 SD" rule: the mean is the
Gaussian centre `CZ`, and `sigma_space` is the spatial standard deviation. In
two-dimensional electrode space, this is implemented as a radius around `CZ`,
not as a threshold on the Gaussian weight value itself.

An electrode is active if it is inside this radius:

$$
a_i =
\begin{cases}
1, & d_i \le \sigma_{\mathrm{space}},\\
0, & d_i > \sigma_{\mathrm{space}}.
\end{cases}
$$

The ground-truth active electrode set is:

$$
\mathcal{A}
= \left\{ i : d_i \le \sigma_{\mathrm{space}} \right\}.
$$

### Data Generation

The data generator creates two conditions:

$$
y_{i,t}^{(1)} = \epsilon_{i,t}^{(1)}
$$

$$
y_{i,t}^{(2)} =
A\,w_i\,g(t - t_0) + \epsilon_{i,t}^{(2)}
$$

Here, `condition 1` is noise only. `condition 2` adds a temporal ERP signal
`g(t - t0)` multiplied by the spatial weight `w_i`.

Monte Carlo datasets are generated by `code/00_generate_montecarlo.R`.

The participant count is controlled by `MC_N_PPT`.

The output data directory is controlled by `MC_DATA_SUBDIR`.

### Main Model Setting

The main model is fitted with:

```text
k = c(20, 20)
full = FALSE
se_mode = sem
```

The SEM used in the model is:

$$
\mathrm{SEM}_{i,t}
= \frac{\mathrm{SD}_{i,t}}{\sqrt{R}},
$$

where `R` is the number of trials per participant per condition.

The model is defined in `code/01_fit_bgam.R`.

The main Monte Carlo runner is `code/09_run_montecarlo_sem.R`.

The current Slurm job status is recorded in `EXPERIMENT_STATUS.md`.
