# Code Reading Guide

Read these files in order when explaining the current project.

## 1. Current Experiment State

Start with:

```text
EXPERIMENT_STATUS.md
CODE_INVENTORY.md
PROJECT_STRUCTURE.md
```

These files explain the current SSH jobs, active scripts, and directory layout.

## 2. Data Generation

Read:

```text
code/00_generate_data.R
```

Current key point:

```text
spatial_weight = Gaussian(distance), if distance <= sigma_space
spatial_weight = 0,                  if distance > sigma_space
```

Ground-truth active electrodes are now defined by:

```text
spatial_distance <= sigma_space
```

Monte Carlo datasets are generated by:

```text
code/00_generate_montecarlo.R
```

The participant count is controlled by:

```text
MC_N_PPT
```

The output directory is controlled by:

```text
MC_DATA_SUBDIR
```

## 3. Model Fitting

Read:

```text
code/01_fit_bgam.R
```

Main model form:

```text
eeg_mean | se(...) ~
    condition +
    (1 + condition | participant) +
    t2(xproj, yproj, time, by = condition,
       k = c(k_xy, k_t),
       full = full)
```

Important settings:

```text
se_mode = sd | sem | reff | none
k_xy, k_t
full
```

Current main target is SEM:

```text
se_mode = sem
```
